# CALA SOLARA

**CALA SOLARA** is a 100% original, offline 3D open-world crime game built for the [make.fun `gta6-01` bounty](https://make.fun/bounty/gta6-01?ref=41fw6r6c), set in a sun-soaked volcanic-bay coastal metropolis.

## Highlights
- **HDR Bloom & Filmic 3D Engine**: Custom GLSL HDR bloom post-processing, ACES filmic grading, crisp follow-camera directional shadows, procedural PBR textures with emissive window maps, animated turquoise-to-sapphire ocean surf shader, and ridged volcanic terrain.
- **6 Distinct Districts & Organic Coastline**: Explore *Palmera Strip*, *Solara Financial Core*, *Barrio Viejo*, *Puerto Caldera*, *Puente del Sol* suspension bridge, and *Monte Faro* volcanic lighthouse island on foot, by car, motorcycle, or coastal speedboat.
- **Tactical 5-Star CSPD Dispatch**: Escalating pursuit tiers with PIT flankers, avenue roadblocks with flares and tire-puncturing spike strips, armored SWAT trucks that dismount on-foot squads, and Air-1 helicopter volumetric searchlight lockdowns.
- **Multi-Stage Story Campaign, Active Crew & Turf Control**: 8 multi-stage missions with character radio comms, 3 switchable crew specialists (`[Q]`/`[C]`), 6-district turf takeovers, AI street races, stunt jumps, Solara Customs garage tuning, procedural Web Audio + 3 original FM radio stations, and 3-slot `localStorage` save/load.

## Run Locally
```bash
node serve.ts
# Open http://localhost:8080 in desktop Chrome
```

## Build Dossier
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
